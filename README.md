# Юридический навигатор — лендинг

RAG-ассистент по корпоративным юридическим процедурам, который отвечает строго по документу и честно признаёт, когда ответа нет.

**Открыть:** https://knyazkovstudios1.github.io/legal-navigator/
**Мини-апп:** https://knyazkovstudios1.github.io/legal-navigator-miniapp/

## Три адреса в `app.js`

Вся настройка — три константы в начале файла.

| Константа | Что вписать |
|---|---|
| `TG_LINK` | Ссылка на бота. После `/newapp` в BotFather можно поставить прямую ссылку на мини-апп |
| `CHAT_URL` | Production Chat URL основного workflow n8n. Пусто — работает демо-режим |
| `NOTIFY_URL` | Production URL workflow «уведомление на почту». Пусто — письма не шлются |

## Почта

После каждого ответа сайт зовёт `NOTIFY_URL` и **не ждёт результата** — письмо не должно задерживать интерфейс. Уведомление уходит на `knyazkovstudios@gmail.com` всегда; автоответ клиенту — только если он сам ввёл адрес в поле под ответом и адрес прошёл проверку формата.

Workflow для этого импортируется отдельно (`workflow-notify.json`) и оцениваемый процесс не затрагивает.

## 3D-сцена

`scene.js` рисует поток вопросов, проходящий проверку и расходящийся на три ветки. Это не декор: на сцене показана та же логика, о которой говорит страница.

Сцена не запускается при `prefers-reduced-motion`, при отсутствии WebGL и когда вкладка скрыта. Любой сбой оставляет статичный градиент — страница не ломается.
