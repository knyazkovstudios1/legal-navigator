# Юридический навигатор — лендинг

Страница-портфолио проекта: RAG-ассистент по корпоративным юридическим процедурам, который отвечает строго по документу и честно признаёт, когда ответа нет.

**Открыть:** https://knyazkovstudios1.github.io/legal-navigator/

Мини-апп (Telegram): https://knyazkovstudios1.github.io/legal-navigator-miniapp/

## Ассистент в первом экране

По умолчанию работает демо-режим: ответы берутся из `demo-responses.json`, сгенерированного прогоном настоящих Code-нод n8n. Чтобы включить живые ответы, впишите production Chat URL ноды Chat Trigger в константу `CHAT_URL` в `index.html`.

Перед включением живого режима обязательно:

1. В биллинге OpenAI создайте отдельный проект и ключ, поставьте **жёсткий месячный лимит**. Это единственное, что реально ограничивает ущерб от публичного эндпоинта.
2. В ноде OpenAI Chat Model выставьте `Maximum Number of Tokens` около 400.
3. В n8n добавьте после Chat Trigger проверку длины вопроса, чтобы длинные запросы не доходили до модели.

`allowedOrigins` в Chat Trigger заполнить стоит, но **защитой это не является**: CORS — ограничение браузера, а не сервера. `curl` его игнорирует, заголовок `Origin` подделывается одной строкой.

## Ссылка в Telegram

Сейчас кнопки ведут на `https://t.me/tg_crm_vibecoder_bot?start=landing` — открывается чат с ботом, дальше пользователь нажимает кнопку меню.

Чтобы мини-апп открывался **одним касанием**, создайте приложение в BotFather: `/newapp` → выбрать бота → название → описание → картинка 640×360 → на запрос GIF отправить `/empty` → URL мини-аппа → короткое имя латиницей. После этого поставьте в `TG_LINK` ссылку вида `https://t.me/tg_crm_vibecoder_bot/<short_name>?startapp=landing`.
